# Contributing

Fixes and extensions are welcome. Report bugs and ideas as GitHub Issues; security
problems privately, as described in [SECURITY.md](SECURITY.md). Contributions are made
under the [MIT license](LICENSE) of the project. The documentation in `docs/` explains how the
converter works:

| You want to … | Read |
|---|---|
| find out why a document converts wrongly | [docs/troubleshooting.md](docs/troubleshooting.md) |
| understand the code | [docs/architecture.md](docs/architecture.md) |
| understand the MIF the code reads | [docs/mif-primer.md](docs/mif-primer.md) |
| add a MIF feature or an output format | [docs/extending.md](docs/extending.md) |
| know why something is done the way it is | [docs/decisions.md](docs/decisions.md) |

## Rules

- **Standard library only** for the converters. Tests may use pandoc and Asciidoctor and
  skip when they are missing.
- **Never add real documents** – not your own, not anyone else's. Rebuild the part that
  matters with neutral text in `samples/sample/make_sample.py` or in a unit test.
- **Every fix gets a test** that fails without it.
- **Match the surrounding code**: short functions, docstrings that say what and why,
  comments only where the reason is not obvious. Write special characters in the source
  as `\N{...}` escapes, not as invisible characters.
- **Warn, don't fail**: what cannot be converted is left out with one warning.

## Tests

```
python3 -m unittest discover tests
```

`samples/sample/sample.mif` and `sample-mif7.mif` are generated by
`samples/sample/make_sample.py` (the tests run it). If you change the output on purpose,
regenerate the expected files and check every changed line:

```
UPDATE_EXPECTED=1 python3 -m unittest discover tests
```

With pandoc and Asciidoctor installed, more tests run: escaped text must come back
unchanged through both, and the sample's tables, footnotes and links must be recognised.
The same tests run on GitHub for every pull request (Python 3.9 and newer, with and
without pandoc and Asciidoctor); a pull request can only be merged when they pass.
